## How to import

1. Copy **Recovered_Markdown/** into your Obsidian Research Archive vault.
2. Open **Experiment_1B_Explicit_Baseline.md** (or another experiment) in Obsidian Reading view to check formatting.
3. Keep **Original_Word_Sources/** as the unmodified archival source files. The original submitted ZIP has not been altered.
4. Use the existing Series I research analysis/results separately; these transcripts do not update experiment outcomes.

## Recovery boundaries

- Original Word files were preserved **byte-for-byte** as submitted. SHA-256 hashes are recorded in **QA_Report.json**.
- All six model sections from every source were retained. There are 174 model-response/trial sections across these nine recovered documents (54 in the three-level Compression Gradient document).
- All **333 embedded Word equations** were transferred to Markdown LaTeX; the **two Word tables** were converted to Markdown tables. All nine files passed a Markdown parser check.
- Editorial formatting was reconstructed; headings, trial locators, and Markdown presentation are not evidence of original platform output formatting.
- No substantive answers were corrected, reconciled, paraphrased, or supplemented. Preserve the Word copies when exact original visual layout matters.
- **Experiment 5, Compression Gradient (Level 1, Grok):** The source used a malformed trial divider, `—-`. It was interpreted as the divider between recorded trials 1 and 2, because it appears between two response blocks. The unchanged source remains included.
- **Experiment 7B:** The source contains the literal placeholder **`[PASTE META'S FINAL OUTPUT FROM EXPERIMENT 7A HERE]`**. This was retained as an explicit gap. No relay input was reconstructed or substituted from Experiment 7A; evidence of the *actually transmitted* input is needed to resolve it.
- **Experiment 1A** is not in this batch ZIP; it was supplied separately in the conversation and is not included in this package.

The documents are reconstructed **from the supplied Word files**, not independently verified against the original chat-platform export bytes. Consult the source DOCX for provenance-sensitive uses.
